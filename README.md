# aDVanceERP - Módulo de Caja Registradora

## Descripción

Módulo de gestión de caja registradora para el sistema **aDVanceERP**. Proporciona funcionalidades completas para:

- 🔓 **Apertura/cierre de turno**: Control del inicio y fin de jornada de caja
- 💰 **Movimientos de caja**: Registro de ingresos, egresos y movimientos de dinero
- 📋 **Detalle de turnos**: Consulta y análisis detallado de operaciones por turno

## Tecnología

- **Lenguaje**: C#
- **Licencia**: GPL-3.0

## Características

- Gestión integral de turnos de caja
- Registro detallado de movimientos monetarios
- Reportes por turno
- Integración con el ecosistema aDVanceERP
